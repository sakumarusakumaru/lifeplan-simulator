# ver4 Lite の設計と、ビジネスモデルの提案

作成: 2026年10月27日

## 1. なぜ Lite が要るか

ver4 の入力は、細かく分けると 200 項目を超える。正確さと引き換えに、はじめての人が最後までたどり着けない。
ライフプランは、数字が全部そろってから始めるものではない。「ざっくりの答え」を先に見せて、気になった人だけが詳しく入れる順番にする。

- Lite: 3分・14問・登録なし。答えをすぐ見せる
- ver4: Lite の入力を引き継いで、足りないところを足していく

## 2. Lite の入力項目（4枚のカード・14問）

| カード | 項目 | 聞き方の工夫 |
|---|---|---|
| 01 家族 | あなたの年齢 | 生年月日ではなく年齢だけ |
| | 配偶者（いない／いる・年齢） | |
| | 子ども（人数・それぞれの年齢） | 「＋子どもを足す」で増やす |
| | 学校（ずっと公立／大学だけ私立／中学から私立） | 子がいるときだけ出す。段階ごとには聞かない |
| 02 収入 | 働き方（会社員・公務員／自営業） | 年金の種類はここから決める |
| | 年収（額面） | 「源泉徴収票の支払金額」と書く |
| | 何歳まで働くか | 既定65歳 |
| | 退職金の見込み | わからなければ0（少なめに見る） |
| | 配偶者の働き方・年収 | 会社員／パート／働いていない／自営業 |
| 03 支出と住まい | 毎月の生活費（住まい・教育費を除く） | 家計調査の目安を添える |
| | 住まい（賃貸の家賃／ローンの返済額と残り年数／ローンなし） | ローンは残高ではなく「毎月の返済額」で聞く（通帳で分かる） |
| 04 いまあるお金 | 預金・現金 | |
| | 投資の合計 | NISA・特定口座・投信・株を分けない |
| | 毎月の積立 | 新NISAに入るとみなす |

聞かないで、前提で置いたもの（画面の「この計算で置いている前提」に全部出す）
- 物価1.5%・昇給1.5%（物価並み）・投資の利回り4%・ローン金利1%・持ち家の固定資産税など年10万円
- 年金: 会社員は22歳から働き終わるまで厚生年金、今の年収で見積もる。自営業は国民年金満額。65歳から
- 投資はすべて新NISA、iDeCo・保険・車・介護・相続・副業・不動産投資はなし
- 老後も同じ生活費、100歳まで

結果の見せ方
- 一言の答え: 「100歳まで、お金は足りる見込み」／「○歳で、お金が足りなくなる見込み」
- 数字は3つだけ: 働き終わる年のお金、100歳のお金、いまの1年の収支（すべて今の価値）
- グラフは1本（預金＋投資）。0を下回ると赤
- 「小さく変えると、どうなる？」: 生活費−1万円／積立＋1万円／2年長く働く、の効果
- 「この内容でver4を開く」: 入力を ver4 に引き継ぐ。ver4 にすでに入力があれば確認を出す（引き継ぎ書と相続の設定は残す）

計算は ver4 と同じエンジン（lib/v4/calc）をそのまま使う。Lite のコードは app/lite・components/lite・lib/lite・store/lite で、ver4 のファイルは変えていない（ver4 はタグ v4.20.0-stable で保存）。

## 3. ビジネスモデルの提案

### 結論

サブスク（自動で毎月引き落とし）より、「1年ごとの買い切り（年度パス）」をすすめる。

| | 内容 | 値段（案） |
|---|---|---|
| Lite | 3分で答え。登録なし | 無料 |
| ver4 年度パス | 詳しい入力・比較・制度チェック・名目と今の価値の切り替え・振れ幅（モンテカルロ）・JSON保存 | 1,980円／年（自動更新なし） |
| もしもパック | 遺族年金・必要保障額・相続税（一次・二次・一人ずつ）・家族に渡す引き継ぎ書 | +980円（その年度） |
| まとめて | 年度パス＋もしもパック | 2,480円 |

### サブスクにしない理由

- ライフプランは毎月使うものではない。使うのは、結婚・出産・住宅購入・転職・定年前などの節目と、年に一度の見直し。毎月の引き落としだと「使っていないのに払っている」と感じて解約される
- ただし税・年金の制度は毎年変わり、こちらは毎年直す手間がかかる。だから完全な買い切りでもなく「その年度の制度で計算できる権利」を売る。翌年も使いたい人だけが買い直す
- 自動更新をしないので、解約の手続きや「解約できない」という不満が起きない

### もしもを別料金にする理由

- 必要な人がはっきりしている（子育て世帯・住宅ローンのある人・親の相続を考え始めた50代）。払う理由が分かりやすい
- 引き継ぎ書は印刷して家族に渡す「成果物」があるので、買い切りの納得感が高い
- 値段の目安: 書店のエンディングノートが1,000〜2,000円。それより安く、自分の数字が最初から入っている

### 値段の考え方

- 家計簿アプリの有料プランは月500円前後（年6,000円）。それより一段安くして「年に一度の見直しに1,980円」
- FPの有料相談は1回数千円〜1万円台。「相談の前に自分で整理しておく道具」として、相談1回より安い位置に置く
- 最初の100人などに半額で出して、値段への反応を見るのもよい

### その次（法人・教育）

- FP・保険代理店向け: お客さんの入力をJSONで受け取って一緒に見る。1人あたり月3,000〜5,000円の業務ライセンス
- 企業の福利厚生・ライフプラン研修: 社員数で年契約
- 大学・講座: 授業での利用は無料にして、名前を広げる（大阪芸大・関西大・宣伝会議の受講生）

## 4. 仕組み（お金をもらうための作り）

いまは入力がすべてブラウザの中だけにあり、サーバーがない。この「データを外に出さない」は強みなので残す。

- 第1段階（今回）: Lite を無料で公開。トップページから入れる
- 第2段階: Stripe の決済ページで買うと「ライセンスキー」（署名つきの文字列）がメールで届く。サイトに貼ると ver4・もしもが開く。キーの確認はブラウザの中でできる（公開鍵で署名を確かめる）ので、入力データはサーバーに送らない。アカウント登録もいらない
- 第3段階: 必要になったら、ログインと端末をまたいだ保存（暗号化して保存）を足す

数を見るのは、個人の情報を集めない計測（Vercel Analytics など）で十分。見る数字は「Lite で結果まで行った人」「ver4 を開いた人」「買った人」の3つ。

## 5. 始める前に確かめること

- 販売する主体: さくまる個人か、合同会社ジブンか。博報堂の兼業の規定の確認
- 特定商取引法の表記（販売者・連絡先・返金の条件）と、利用規約の有料部分の追記
- 投資の助言にならない範囲（一般的な計算道具で、個別の商品をすすめない）は今の注意書きのまま守る
- 消費税・インボイスの扱い
